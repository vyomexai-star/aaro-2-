# React + Vite Starter

A minimal JavaScript starter built with React and Vite. Website sections have
not been added yet.

## Development

From this folder, run:

```sh
npm run dev
```

The workspace uses pnpm for dependency management. To install dependencies in
the Replit workspace, run `pnpm install` from the workspace root.

## Production build

```sh
npm run build
```

The production files are written to `dist/public/`.
