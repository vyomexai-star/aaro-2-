# Aaro Farms

A responsive, single-page brand website for Aaro Farms, built with React and
Vite. Product details, testimonials, and contact methods are marked as
placeholders until approved information is available.

## Development

From this folder, run:

```sh
npm run dev
```

The workspace uses pnpm for dependency management. To install dependencies in
the Replit workspace, run `pnpm install` from the workspace root.

## Production build

```sh
npm run build
```

The production files are written to `dist/public/`.
